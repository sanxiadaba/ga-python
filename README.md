# 遗传算法求解 25 城 TSP

25 个城市，要找到一条把每个城市各走一遍、最后回到起点、总距离最短的路线。

遗传算法不看地图、不算几何，只是一代一代地随机试：

1. 随机生成 80 条路线
2. 留下最短的几条
3. 挑两条路线各取一段，拼成新路线（交叉）
4. 偶尔把新路线里的一段顺序倒过来（变异）
5. 差的淘汰，回到第 2 步，重复 300 代

## 怎么用

在仓库目录里执行：

```
python main.py
```

终端打印：

```
最优路线    6,23,4,...,13,5
最优距离    4.578091652396
已知最优    4.267835351807
最优差距    7.269641%
耗时        0.361 秒
路线图      ...\output\route.png
适应度图    ...\output\fitness.png
```

`已知最优` 是用整数规划算出来的标准答案。默认这次差 7.3%，换 10 个种子平均差 3.2%，
偶尔能正好撞上标准答案。

同时在 `output/` 里生成两张图：

![最短路线](output/route.png)

![每一代的最短距离](output/fitness.png)

## 参数

```
python main.py --seed 3 --population-size 100 --generations 500
```

常用的就 `--seed`、`--population-size`、`--generations`，其余看 `python main.py --help`。

想让结果更接近标准答案，可以在每代之后加一步局部搜索，比如 2-opt：把路线里交叉的两条边换开，
直到没有交叉为止。那样就不算纯遗传算法了，这个库没有加。
